5. Games Played Overrides

Any player with PA > 0, IP > 0, or BF > 0 defaults to 3 GP. Add an override only if that player actually appeared in 1 or 2 games. Zero-stat roster entries are ignored.

No overrides. All active series participants will receive 3 GP.
